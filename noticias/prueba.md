Hola esto es una **prueba** para escribir artículos en MarkDown

## El MarkDown

Se trata de un nuevo formato de escritura donde podemos crear contenido directamente mediante **escritura con códigos**.

## Consideraciones

En MarkDown podemos hacer cosas interesantes como 

1. Hacer Listas
2. ~Comprar Chorizos~
3. Enviar datos.

También podriamos codigo en *cualquier lenguaje*

`<text align="center">`
